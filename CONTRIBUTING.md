# Contributing

Thanks for helping improve Pitfall: The Modified Adventure.

- Do not submit original game binaries, data files, music, artwork, or other
  copyrighted retail assets.
- Keep third-party attribution and license notices intact.
- Describe the Windows version, display configuration, controller, and exact
  reproduction steps when reporting compatibility problems.
- Avoid committing generated DLLs, executables, logs, captures, or extracted
  sound samples.

The project is currently stabilizing its first release, so interfaces and
repository layout may still change.
